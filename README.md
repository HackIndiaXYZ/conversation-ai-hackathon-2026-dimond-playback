# Proxa Echo – Real-Time Conversational AI Avatar

## 🚀 Overview
Proxa Echo is a real-time, browser-based conversational AI avatar designed for pharmaceutical and life sciences sales training. It enables users to practice high-stakes conversations with simulated healthcare professionals (HCPs).

This project demonstrates a low-latency (<300ms), voice-driven AI avatar with synchronized lip movement, expressive facial animation, and multi-turn conversation capabilities.

---

## 🎯 Features

- 🎤 Real-time voice input (Speech-to-Text)
- 🤖 LLM-powered responses (GPT-4 / Claude)
- 🔊 Real-time Text-to-Speech (TTS)
- 🧑‍⚕️ Avatar with lip-sync (viseme-based animation)
- 😊 Facial expressions (neutral, engaged, skeptical, positive)
- 🔁 Multi-turn conversation (session memory)
- 🌐 Fully browser-based (Chrome, Safari, Mobile supported)
- ⚙️ Configurable persona (name, role, personality)
